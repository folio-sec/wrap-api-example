# サンプルラップサービス

## 開発

- PHP 8.1+
- ext-bcmath

**macOS / Linux:**
```shell
# 準備
git init
git add .
git commit -m init

# setup
composer install

# test
vendor/bin/phpunit
```

**Windows (PowerShell):**
```powershell
# 準備
git init
git add .
git commit -m init

# setup
composer install

# test
vendor\bin\phpunit
```
