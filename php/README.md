## サービス概要

このアプリケーションは、FOLIOで提供されるロボアドバイザーサービスを模倣したバックエンドAPIサーバーです。

- ロボアドバイザーは、気軽に投資が出来るサービスとなっています
- お客様は「10万円投資がしたい」となったら、10万円を新規注文で入れていただくと投資が始められます
- どういった銘柄を運用するかは、お客様ではなく、サービスで管理されたポートフォリオに基づき運用されます

### サービスについて

- **顧客の口座**
  - 初めて資金を投入することを新規注文と呼び、この注文を入れることで口座が開き資産運用が始まります
  - 口座の中で資産を管理することになります
- **顧客口座の資産**
  - 顧客は現金と銘柄及びその資産額を口座内で保有します
    - 簡略化のために、顧客は銘柄ごとに保有額（円）を保持します（例: Toyopa銘柄を 500 円分保有する）
    - 本来は、口座には株数が保持されますが、各銘柄を資産額（円）で直接保有するものとします（市場価格の概念も取り扱いません）
  - また、総資産の内、5%は常に現金で保持します
    - 例: 総資産100万円のうち5万円（5%）を現金として保持し、残り95万円分をいくつかの銘柄で保有する
- **最適ポートフォリオ**
  - サービスで管理する、保有銘柄を100%配分した組み合わせのことを最適ポートフォリオと呼びます
    - 例: 合計100%のうち、Toyopa銘柄を40%・Somy銘柄を60%の最適ポートフォリオが現在設定されている
  - 購入時・売却時・リバランス時には、注文後の資産比率が __現在の最適ポートフォリオ__ に近づける形での調整を実施します
    - 例: 先のポートフォリオ例の場合、100万円を新規注文した場合、 5万円の現金 + Toyopa銘柄38万円分 + Somy銘柄57万円分 が口座内で管理されます
    - なお、APIを叩くと __即時__ 売買が成立し資産に反映出来るものとします（受け渡し日などの概念はありません）
- **各種注文**
  - __新規注文__
    - 初めて資金を投入することで、新規に口座開設が行われ資産運用が始まるもの
  - __追加注文__
    - 新規注文後に、追加で資金を投入すること
  - __全売却注文__
    - 運用中の銘柄を全て売却して現金にすること
  - __リバランス注文__
    - 運用されている資産を、サービスで保有する最適ポートフォリオに近づけるよう調整すること
    - 例:
      - 新規注文時には、最適ポートフォリオが `Toyopa銘柄30% + Somy銘柄70%` で構成される場合、顧客口座においても同様の資産配分となる
      - その後にサービス上で最適ポートフォリオが `Toyopa銘柄50% + Somy銘柄50%` に更新される
      - 更新後に、リバランス注文を入れると、顧客の口座も最新の最適ポートフォリオ通りの内容になる
        - この場合、Toyopa銘柄が20%分購入され、Somy銘柄が20%分売却される
