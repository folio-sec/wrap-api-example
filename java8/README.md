# サンプルラップサービス

## 開発

- Java 8+

**macOS / Linux:**
```shell
# 準備
git init
git add .
git commit -m init

# セットアップ
./mvnw test-compile

# テスト実行
./mvnw test
```

**Windows (PowerShell):**
```powershell
# 準備
git init
git add .
git commit -m init

# セットアップ
.\mvnw.cmd test-compile

# テスト実行
.\mvnw.cmd test
```
